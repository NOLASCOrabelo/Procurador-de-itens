Um ID válido do AnyDesk tem 9 DÍGITOS:
  ✓ Exemplo: 1 861 952 576
  ✓ Formato: X XXX XXX XXX (com espaços)
  ✓ Sem espaços: 1861952576

  LIMITAÇÃO IMPORTANTE
═══════════════════════════════════════════════════════════════

OBTER IDs REMOTOS É DIFÍCIL!
-----------------------------
Para obter o ID de uma máquina remota, você precisa:

  1. ACESSO ADMINISTRATIVO à máquina remota
  2. POWERSHELL REMOTING habilitado (Enable-PSRemoting)
  3. OU acesso físico/RDP à máquina

POR QUÊ?
--------
O ID do AnyDesk fica em um ARQUIVO LOCAL:
  Windows: %APPDATA%\AnyDesk\service.conf
  Linux: ~/.anydesk/service.conf

Não é possível ler este arquivo remotamente sem permissões especiais.
