═══════════════════════════════════════════════════════════════
  PASSO A PASSO PARA EXECUTAR
═══════════════════════════════════════════════════════════════

1. ABRIR POWERSHELL COMO ADMINISTRADOR
   - Clique com botão direito no ícone do PowerShell
   - Selecione "Executar como Administrador"

2. NAVEGAR ATÉ A PASTA DO SCRIPT
   cd "C:\Users\Thiago\Desktop\Nolasco\Agents\Procurador de item"

3. PERMITIR EXECUÇÃO DE SCRIPTS (se necessário)
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

4. EXECUTAR O SCRIPT
   .\descobrir_anydesk_CORRIGIDO.ps1

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEMA: "Execution Policy"
SOLUÇÃO:
  Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

PROBLEMA: "Missing closing '}'"
SOLUÇÃO:
  Use o arquivo descobrir_anydesk_CORRIGIDO.ps1

PROBLEMA: Script não encontra AnyDesks
SOLUÇÃO:
  - Verifique se o firewall permite conexões na porta 7070
  - Execute como Administrador
  - Verifique se há AnyDesks ativos na rede
