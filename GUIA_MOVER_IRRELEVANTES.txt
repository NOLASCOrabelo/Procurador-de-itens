═══════════════════════════════════════════════════════════════
  GUIA: MOVER ITENS NÃO ENCONTRADOS (IRRELEVANTES)
═══════════════════════════════════════════════════════════════

CENÁRIO:
--------
Você tem 80 itens em uma pasta.
Procurou 43 termos relevantes usando o procurar_itens.ps1.
Os outros itens (que NÃO contêm nenhum dos 43 termos) são irrelevantes.
Você quer MOVER esses irrelevantes para outra pasta.


═══════════════════════════════════════════════════════════════
  SCRIPTS DISPONÍVEIS
═══════════════════════════════════════════════════════════════

1. mover_itens_nao_encontrados.ps1 (COMPLETO)
   → Versão interativa com confirmações
   → Mostra preview dos itens
   → Mais seguro para primeira vez

2. mover_itens_nao_encontrados_rapido.ps1 (RÁPIDO)
   → Aceita parâmetros na linha de comando
   → Menos perguntas
   → Ideal para uso repetido


═══════════════════════════════════════════════════════════════
  COMO USAR - VERSÃO COMPLETA
═══════════════════════════════════════════════════════════════

PASSO 1: Execute o script
--------------------------
.\mover_itens_nao_encontrados.ps1


PASSO 2: Informe os termos RELEVANTES
--------------------------------------
Digite os termos RELEVANTES que voce procurou (separados por virgula ou espaco):
> termo1, termo2, termo3

Exemplo:
> 2024, relatorio, vendas


PASSO 3: Informe a pasta ORIGEM
--------------------------------
Digite o caminho da pasta ORIGEM (onde estao os itens):
> C:\Meus Documentos\Pasta80Itens


PASSO 4: Informe a pasta DESTINO
---------------------------------
Digite o caminho da pasta DESTINO (para onde mover os irrelevantes):
> C:\Meus Documentos\Irrelevantes

Se a pasta não existir, o script pergunta se quer criar.


PASSO 5: Confirme a operação
-----------------------------
O script mostra:
  - Quantos itens são relevantes (ficarão)
  - Quantos itens são irrelevantes (serão movidos)
  - Preview dos primeiros itens a mover

Confirme com S (Sim) ou N (Não)


PASSO 6: Aguarde a conclusão
-----------------------------
O script move os itens e mostra o progresso.


═══════════════════════════════════════════════════════════════
  COMO USAR - VERSÃO RÁPIDA
═══════════════════════════════════════════════════════════════

MODO 1: Interativo (sem parâmetros)
------------------------------------
.\mover_itens_nao_encontrados_rapido.ps1

O script pergunta:
  - Pasta origem
  - Pasta destino
  - Termos relevantes


MODO 2: Com parâmetros (mais rápido)
-------------------------------------
.\mover_itens_nao_encontrados_rapido.ps1 -PastaOrigem "C:\Origem" -PastaDestino "C:\Destino" -Termos "termo1","termo2","termo3"

Exemplo real:
.\mover_itens_nao_encontrados_rapido.ps1 -PastaOrigem "C:\Documentos\80Itens" -PastaDestino "C:\Documentos\Irrelevantes" -Termos "2024","relatorio","vendas"
