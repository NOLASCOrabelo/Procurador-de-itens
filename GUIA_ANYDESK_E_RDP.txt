═══════════════════════════════════════════════════════════════
  COMO CONECTAR VIA RDP
═══════════════════════════════════════════════════════════════

MÉTODO 1: Linha de comando
---------------------------
1. Pressione Win + R
2. Digite: mstsc /v:IP_DA_MAQUINA
3. Exemplo: mstsc /v:192.168.1.100
4. Clique OK
5. Digite usuário e senha


MÉTODO 2: Interface gráfica
----------------------------
1. Pressione Win + R
2. Digite: mstsc
3. Clique OK
4. Na janela que abrir:
   - Campo "Computador": Digite o IP (ex: 192.168.1.100)
   - Clique "Conectar"
5. Digite usuário e senha


MÉTODO 3: Menu Iniciar
-----------------------
1. Menu Iniciar
2. Procure: "Conexão de Área de Trabalho Remota"
3. Digite o IP da máquina
4. Clique "Conectar"


═══════════════════════════════════════════════════════════════
  COMO CONECTAR VIA ANYDESK
═══════════════════════════════════════════════════════════════

PROBLEMA:
---------
Para conectar via AnyDesk, você precisa do ID de 9 dígitos.
Exemplo: 1 861 952 576


SOLUÇÃO 1: Se a máquina tem RDP habilitado
-------------------------------------------
1. Conecte via RDP primeiro (veja acima)
2. Na máquina remota, execute:
   .\obter_id_anydesk.ps1
3. Anote o ID mostrado
4. No seu AnyDesk local, digite esse ID


SOLUÇÃO 2: Se a máquina NÃO tem RDP
------------------------------------
Você precisa de acesso físico à máquina:
1. Vá até a máquina fisicamente
2. Execute: .\obter_id_anydesk.ps1
3. Anote o ID
4. Volte ao seu PC e use o ID no AnyDesk


SOLUÇÃO 3: PowerShell Remoting (avançado)
------------------------------------------
Se você tem credenciais de administrador:
1. Na máquina remota, habilite PS Remoting:
   Enable-PSRemoting -Force
2. Use o script: .\descobrir_anydesk_REAL.ps1
3. Forneça credenciais quando solicitado

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEMA: RDP não conecta
--------------------------
Possíveis causas:
  ❌ Firewall bloqueando porta 3389
  ❌ RDP desabilitado nas configurações do Windows
  ❌ Credenciais incorretas
  ❌ Usuário não tem permissão de acesso remoto

Solução:
  1. Verifique se o usuário está no grupo "Usuários de Área de Trabalho Remota"
  2. Verifique firewall da máquina remota
  3. Confirme que RDP está habilitado:
     Painel de Controle > Sistema > Configurações Remotas


PROBLEMA: AnyDesk detectado mas não consigo conectar
-----------------------------------------------------
Possíveis causas:
  ❌ Não tem o ID correto
  ❌ AnyDesk na máquina remota está com senha
  ❌ Acesso não supervisionado não configurado

Solução:
  1. Obtenha o ID correto (9 dígitos)
  2. Se pedir senha, você precisa saber a senha configurada
  3. Configure acesso não supervisionado na máquina remota


PROBLEMA: Script não encontra nenhuma máquina
----------------------------------------------
Possíveis causas:
  ❌ Firewall bloqueando scan de portas
  ❌ Máquinas em subnet diferente
  ❌ Timeout muito curto

Solução:
  1. Execute como Administrador
  2. Verifique se está na mesma rede
  3. Desabilite temporariamente o firewall para teste
