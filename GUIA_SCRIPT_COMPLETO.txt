NOVO SCRIPT: procurar_e_mover_irrelevantes.ps1
-----------------------------------------------
Este script combina as duas funcionalidades em uma única execução:
  1. PROCURA itens relevantes (que contêm os termos)
  2. MOVE itens irrelevantes (que NÃO contêm os termos)


═══════════════════════════════════════════════════════════════
  COMO USAR
═══════════════════════════════════════════════════════════════

PASSO 1: Execute o script
--------------------------
.\procurar_e_mover_irrelevantes.ps1


PASSO 2: Digite os termos relevantes
-------------------------------------
Digite os termos que deseja procurar (separados por virgula ou espaco):
> 456728, 456729, 456730, 456731

Ou com espaços:
> 456728 456729 456730 456731


PASSO 3: Digite a pasta onde procurar
--------------------------------------
Digite o caminho completo da pasta onde deseja procurar:
> C:\Users\Thiago\Desktop\BAIXAS


PASSO 4: Aguarde a busca
-------------------------
O script vai:
  ✓ Escanear todos os arquivos da pasta
  ✓ Mostrar quais arquivos contêm os termos
  ✓ Contar quantos são relevantes e irrelevantes


PASSO 5: Decida se quer mover os irrelevantes
----------------------------------------------
Se houver arquivos irrelevantes, o script pergunta:

Deseja mover esses X arquivos irrelevantes para outra pasta? (S/N):
> S


PASSO 6: Digite a pasta destino
--------------------------------
Digite o caminho da pasta DESTINO (para onde mover os irrelevantes):
> C:\Users\Thiago\Desktop\Upscale


PASSO 7: Confirme a operação
-----------------------------
O script mostra:
  - Preview dos primeiros arquivos a mover
  - Quantos arquivos serão movidos

Confirma mover X arquivos para 'C:\...'? (S/N):
> S


PASSO 8: Aguarde a conclusão
-----------------------------
O script move os arquivos e mostra o progresso.
